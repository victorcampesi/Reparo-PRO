# Reparo PRO

Reparo PRO é um aplicativo multiplataforma em desenvolvimento usando o framework flutter junto da linguagem de programação Dart. O aplicativo tem como propósito facilitar a interação entre clientes e prestadores de serviço de áreas variadas, incluindo tanto autônomos quanto empresas. O aplicativo apresentará um feed dinâmico onde usuários postam suas demandas de serviço e prestadores podem aceitá-las. Também estabelecerá comunicação segura entre ambas as partes, com pagamentos processados dentro da plataforma, sistema de avaliação de prestadores de serviço e rastreamento em tempo real durante percursos.
